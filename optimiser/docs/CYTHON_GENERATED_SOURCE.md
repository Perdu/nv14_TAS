# Minimal native interface source cleanup

The original project shipped `native/_nv14_native.c` generated by **Cython 3.3.0**.
An earlier hybrid package regenerated it using **3.2.4**, yielding tens of
thousands of mechanically changed lines unrelated to TAS search. This package
restores the original 3.3.0-generated file and adds **two localized edits**:

- Decode `beam_width`, `beam_edit_penalty` and `beam_adaptive_inputs` from
  `SearchSpec`'s mapping into the native `nv14_search_spec`.
- Include `beam_width_prunes` in the exported search statistics dictionary.

These edits are **hand-maintained compatibility inserts**, clearly marked
`Hybrid-search ABI bridge` and `Hybrid-search statistic` in the checked-in C
file. They are **not** a claim that Cython 3.3.0 was executed in this build
environment; installation of that exact version was blocked by unavailable
network access. The `.pyx` file is the authoritative definition and already
contains all these fields.

## Regenerating from the `.pyx` (on a machine with Cython 3.3.0)

```sh
python -m pip install 'Cython==3.3.0'
python -m cython --version
python -m cython -3 -o native/_nv14_native.c native/_nv14_native.pyx
python build_native.py
python -m pytest -q tests/test_native_beam_search.py tests/test_local_hybrid_windows.py tests/test_adaptive_repair_cache.py
```

The native `setup.py` compiles the checked-in `.c` by default and does **not**
require Cython on users' machines. Re-running Cython after modifying the
`.pyx` is the correct long-term workflow; do not continue hand-editing
generated output for future features. If regeneration changes more than the
expected interface code, confirm the compiler version and directives first.

## Reviewed change groups

The included `patches/` directory has three sequential `git apply` patches,
relative to the **original user-provided `bruteforcer.zip`** (not v2 or v3):

1. Native beam engine and its marshalling/search public interface.
2. Auto/local orchestration, benchmark, documentation and feature tests.
3. Unrelated test-environment assumptions about preloaded Pillow and video scale.

Apply patches in numeric order from the original `tas optimiser/` folder.
Compiled binaries must be rebuilt; they are intentionally absent from this
source distribution. Existing v3 users can instead replace their source tree
with the cleaned full ZIP, or copy the two native bridge files directly:
`native/_nv14_native.c` (reviewed), and `native/_nv14_native.pyx` (unchanged
from v3), then rebuild.
